### Data Flow

1. **Page load** — Landing page appears. Featured tours fetched live from Google Sheets and rendered as cards.
2. **User clicks chat bubble** — Chat panel slides in from the right.
3. **User asks a question** — The message is sent to the Cloudflare Worker, which calls Gemini 2.5 Flash with the full context (tour database, company FAQs, weather data, persona settings).
4. **AI responds** — Gemini generates a natural-language answer with specific tour details, prices, locations, and packing advice.
5. **Weather integration** — If location is shared, Open-Meteo forecast for the user's location and relevant tour areas is included in the context.

## APIs

### Google Sheets (Tour Data)
- **URL:** `https://docs.google.com/spreadsheets/d/{ID}/export?format=csv&gid={GID}`
- **Auth:** None (sheet shared with "Anyone with the link can view")
- **Usage:** Live CSV export of 30 tours fetched on every chat question
- **Rate limit:** None (Google Sheets export is generous)

### Google Gemini 2.5 Flash (AI Responses)
- **URL:** `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`
- **Auth:** API key stored as Cloudflare Worker secret (`GEMINI_API_KEY`)
- **Usage:** Generates all chatbot responses with full tour/weather/time/distance context
- **Rate limit:** 15 req/min, 1,000 req/day (free tier)
- **Proxy:** Cloudflare Worker (`act-chatbot-proxy`) keeps the key server-side

### Open-Meteo (Weather Forecast)
- **URL:** `https://api.open-meteo.com/v1/forecast`
- **Auth:** None (free, no API key required)
- **Usage:** 14-day forecast for user location, tour locations, and user-mentioned locations
- **Data:** Temperature, precipitation, wind, weather codes, sunrise/sunset
- **Rate limit:** 10,000 req/day (free tier)

### Open-Meteo Geocoding (Location Lookup)
- **URL:** `https://geocoding-api.open-meteo.com/v1/search`
- **Auth:** None
- **Usage:** Converts place names to coordinates for weather and distance lookups
- **Fallback:** Tries exact location → town → county if geocoding fails

### TimeAPI (Current Time)
- **URL:** `https://timeapi.io/api/time/current/zone?timeZone=Europe/Dublin`
- **Auth:** None
- **Usage:** Current Ireland time, date, day of week, DST status
- **Cache:** 5 minutes

### OpenHolidays API (Irish Public Holidays)
- **URL:** `https://openholidaysapi.org/PublicHolidays?countryIsoCode=IE&languageIsoCode=EN`
- **Auth:** None
- **Usage:** All 10 Irish public holidays for the current year
- **Cache:** Session (fetched once per page load)

### OpenRouteService (Driving Distances)
- **URL:** `https://api.openrouteservice.org/v2/directions/driving-car`
- **Auth:** API key stored as Cloudflare Worker secret (`OPENROUTESERVICE_API_KEY`)
- **Usage:** Driving distance and time from user location to tour meeting points
- **Rate limit:** 2,000 req/day (free tier)
- **Proxy:** Cloudflare Worker keeps the key server-side

## Persona: Fiona

The chatbot can adopt the **Fiona** persona — a bubbly, fun, professional, and slightly sassy Irish tour guide. When enabled via the 👔/🧑‍🦰 toggle in the chat header:

- Warm and enthusiastic about Ireland
- Playful, slightly sassy sense of humour
- Uses light Irish phrases in moderation ("Sure look", "Ah now")
- Never unprofessional or overly casual
- Acknowledges persona switches between responses

When disabled, the assistant uses a standard professional tone.

## Deployment

### GitHub Pages (automatic)

Push to the `main` branch of `aklag3-dev/atlantic-coast-tours-chatbot`. The site deploys automatically from the root folder.

### Cloudflare Worker (for AI + Distance)

```bash
cd worker
npm install
npx wrangler login
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put OPENROUTESERVICE_API_KEY
npm run deploy
```

The Worker URL is set in `js/gemini.js` and `js/distance.js` as `PROXY_URL`. Currently deployed at `https://act-chatbot-proxy.symphony-driver-assist.workers.dev`.
